General Summary
This release consolidates a major milestone in civil engineering accuracy, numerical precision, UI ergonomics, and Microsoft Store compliance for CONCRETE MIX DESIGNER. It incorporates the complete algorithmic audit of the enhanced IPT/EPUSP experimental mix design spreadsheet (Helene & Terzian, 1992 — UFPR TC031), a redesigned Settings menu featuring integrated Spreadsheet Scenario selection and custom technical header metadata, a Modeless Dialog architecture with independent Z-Order stacking alongside the main GUI, top bar decluttering, refined Windows 11 Dark Theme styling in the User Manual, complete runtime DLL deployment for the Mocks utilities (MinGW and MSVC), and full bilingual standardization of all institutional and legal documentation (Brazilian Portuguese and US English).

New Features, Adjustments, and Improvements

1. Settings Menu, Spreadsheet Scenario, and Technical Header Identification
- "Spreadsheet Scenario:" Selection in Settings Menu: The "Spreadsheet Scenario:" label and its associated dropdown list (containing Scenarios 0 to 5, including Scenario 5 from the corrected original UFPR academic spreadsheet) have been moved into the top of the "Settings" menu, providing a cleaner and more focused workspace.
- Project Data & Identification Dialog (Ctrl+I): Enables configuring the "Project:", "Responsible:", "Institution:", and "ID / Code:" fields displayed in the Technical Report header (Tab 7), with automatic local persistence via QSettings.

- Free Z-Order Stacking Between Main GUI and Dialogs: All auxiliary dialog windows (User Manual, NBR Technical Standards, About Concrete Mix Designer, and export notifications), with the exception of modal dialogs launched from the "Settings" menu, now operate as independent Modeless windows in the Z-Order.
- Non-Blocking Workflow: Clicking the main window immediately brings it to the front in the Z-Order while reference dialogs remain open in the background; clicking an open dialog or selecting its menu item brings it back to the front without blocking mix design editing.

- Removal of Redundant Toolbar Controls: Removed the "Language:" dropdown list and the "Recalculate All", "NBR Standards", "Manual", and "About" toolbar buttons, as these actions are already organized in the "File", "Language", and "Help" menus in the menu bar.
- Smooth SpinBox Editing (QDoubleSpinBox): Disabled premature trailing-zero auto-completion on every keystroke (`KeyboardTracking(false)`), allowing users to type decimal values naturally and formatting numbers only upon confirmation (`Enter`) or focus change.
- Dark Theme Contrast Fix in User Manual: Updated the internal HTML/CSS styling of the User Manual dialog (`ManualDialog`) to eliminate white background boxes behind inline technical expressions (`<code>`) and table headers (`<th>`) when Windows 11 is in Dark Theme.

- Full Mathematical Fidelity with the Enhanced UFPR Spreadsheet (TC031): Synchronized all input cell dependencies and formula precedents, including the 2nd-degree polynomial w/c vs. fcj regression alongside Abrams' Exponential Law, Lyse's Linear Law, Molinari's Hyperbolic Law, automatic propagation of the w/c ratio across all 15 steps of Tab 3 (Mortar Content α), and unit cost conversions across R$/bag, R$/t, and R$/kg.
